# Tabs Open — an honest count

A tiny program/v1 entry for make.fun's "How Many Tabs Do You Have Open?" bounty. It writes one number — digits only, no words, no punctuation — to `/output/entry.txt`: the honest count of browser tabs open at the moment of entry. Not a round flex and not an absurd shock figure: a specific, lived-in hoarder's count, the kind that accumulates one half-finished project at a time.
